# 📥 Download & Installation

## 1. Clone the Repository

Make sure **Git** is installed on your computer.

Open **Command Prompt**, PowerShell, or Terminal and run:

```bash
git clone https://github.com/AbdelatefOsama/Networking-Labs.git
```

Then move into the project folder:

```bash
cd Networking-Labs
```

---

## 2. Download ZIP

If you don't want to use Git:

1. Open the repository on GitHub.
2. Click **Code**.
3. Select **Download ZIP**.
4. Extract the ZIP file.
5. Open the extracted `Networking-Labs` folder.

# ▶️ How to Use the Labs

## Cisco Packet Tracer Labs

For labs created with **Cisco Packet Tracer**:

1. Install Cisco Packet Tracer.
2. Download or clone this repository.
3. Open the required experiment folder.
4. Locate the `.pkt` file.
5. Double-click the `.pkt` file.
6. Cisco Packet Tracer will open the network topology.
7. Review the topology and configuration.
8. Test connectivity using commands such as:

```text
ping
traceroute
show ip route
show running-config
```

---

## GNS3 Labs

For labs created using **GNS3**:

1. Install GNS3.
2. Open GNS3.
3. Open the required project/topology.
4. Start the network devices.
5. Access the device console.
6. Apply or review the provided configurations.
7. Test connectivity between the devices.
